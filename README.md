# AgentShield

AgentShield is an automated security testing framework for LLM-based AI agents.

The project tests AI agents against common security threats and evaluates how effectively different defenses reduce these vulnerabilities.

## Security Tests

AgentShield focuses on four main attack categories:

- Direct Prompt Injection
- Indirect Prompt Injection
- Tool Misuse / Privilege Escalation
- System Prompt & Data Exfiltration

## Features

- Automated security testing
- Attack success detection
- Tool-call monitoring
- Security test logging
- Before-and-after defense comparison
- Security results dashboard

## Project Structure

- `attacks/` - Security attack test cases
- `evaluation/` - Attack evaluation and scoring
- `defense/` - Security defenses
- `data/` - Test data and malicious documents
- `results/` - Security test results
- `frontend/` - Dashboard and user interface
